# Printf

## DESCRIPTION
---
This project aims to recreate the function printf. Through this project I learned to use a variable number of functions.
This printf function performs fewer conversions, as follows: %cspdiuxX%.

This project is made of multiple functions :

| Functions | Prototype |
|---:|:---:|
|ft_putchar | int ft_putchar(int c);|
|ft_putstr | int ft_putstr(char *s);|
|ft_putnbr | int ft_putnbr(long n);|
|ft_printhex | int ft_printhex(unsigned long n, char c);|
|ft_printp | int ft_printp(unsigned long n);|
|ft_checkp | int ft_checkp(va_list ap);|
|ft_condi | int ft_condi(char s, va_list ap);|
|ft_printf | int ft_printf(const char *s, ...);|
