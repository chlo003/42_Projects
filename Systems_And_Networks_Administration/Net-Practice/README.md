# Net_Practice

## Description

NetPractice is a networking exercice designed to introduce the fundamentals of computer networking.  

The goal of this projet is to configure small-scale simulated networks by assigning IP adresses, subnet masks and default gateways to devices.  

Through 10 levels, I learned how devices communicate within a network and how to troubleshoot common network configuration problems.  


## Instructions

### 1. Launch the training interface

Download and extract the NetPratice files provides with the project.  

Open a terminal in the extracted directory and run: `./run.sh`  


### 2. Complete the levels

Enter your login in the training interface to load your personal configuration.  

Complete the 10 levels by modifying the network settings until each configuration is valid.  

Use the "Check again" button to verify your configuration.  


### 3. Export and submission

After succesfully completing each level, click the "Get my config" button to export the configuration.  

Save the 10 exported configuration files at the root of the Git repository, with one file per level.  

Make sure that all 10 configuration files are included in the final submission.
